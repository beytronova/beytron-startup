# Automation Testing

Use this skill when QA work needs repeatable automated coverage or CI validation.

## Responsibilities

- Select the correct automation layer.
- Design stable selectors and fixtures.
- Keep tests deterministic and isolated.
- Identify flake sources.
- Integrate reporting into CI.

## Rules

- Prefer user-visible selectors for E2E tests.
- Avoid arbitrary sleeps.
- Keep test data controlled.
- Separate smoke, regression, and full suites.
- Document known flake risk and retry policy.

## Outputs

- Automation plan.
- Test implementation guidance.
- CI integration notes.
- Flake risk report.
- Coverage gap list.
