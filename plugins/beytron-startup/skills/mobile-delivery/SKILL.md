# Mobile Delivery

Use this skill when work involves Flutter, iOS, Android, mobile QA, mobile release, native integrations, or app-store readiness.

## Responsibilities

- Select Flutter, iOS, or Android implementation guidance.
- Validate architecture, state management, platform APIs, accessibility, privacy, and test strategy.
- Require target repository instructions before code changes.
- Keep mobile implementation tied to approved Jira tickets and PRD scope.

## Outputs

- Mobile implementation plan.
- Test plan.
- Risk list.
- Release readiness notes.
