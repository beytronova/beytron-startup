# QA Release Governance

Use this skill when work needs QA planning, automated test strategy, release preparation, rollback planning, security review, or release approval.

## Responsibilities

- Select unit, integration, E2E, mobile, and regression test strategy.
- Identify flaky test risk, data setup, selectors, reports, and CI requirements.
- Validate release notes, migration plan, monitoring, rollback, and approval status.
- Treat security uncertainty as a blocker.

## Outputs

- QA plan.
- Automation plan.
- Release readiness summary.
- Blockers and required approvals.
