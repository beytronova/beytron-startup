# Repo Bootstrap

Use this skill when an approved idea is ready to become a product repository.

## Required Approval

Repository creation requires:

```text
Approval Status = APPROVED_FOR_REPO_CREATION
```

Development still requires:

```text
Approval Status = APPROVED_FOR_DEVELOPMENT
```

## Responsibilities

- Validate approval status.
- Confirm PRD, architecture, tickets, and ownership are ready.
- Propose repository name and structure.
- Use project-template rules.
- Avoid creating product code during bootstrap planning.

## Outputs

- Repository proposal.
- Bootstrap checklist.
- Initial documentation plan.
- Handoff to development approval.
