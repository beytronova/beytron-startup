# Data Analytics

Use this skill when product, growth, release, or discovery work needs metrics, tracking, dashboards, or evidence.

## Responsibilities

- Define KPIs and guardrail metrics.
- Create event tracking plans.
- Map funnels and conversion points.
- Specify dashboard and reporting needs.
- Identify data quality risks.

## Rules

- Track only what is needed.
- Avoid sensitive data collection unless justified and approved.
- Define event names, properties, triggers, and owners.
- Include privacy and consent implications.

## Outputs

- Metrics plan.
- Event tracking plan.
- Funnel definition.
- Dashboard requirements.
- Data quality risks.
