# Web Backend Delivery

Use this skill when work involves web frontend, backend services, APIs, auth, database changes, integrations, observability, or deployment preparation.

## Responsibilities

- Select the correct stack guidance for web or backend work.
- Keep UI, services, hooks, API contracts, auth, migrations, and logging aligned with architecture.
- Require tests and build checks appropriate to the stack.
- Block implementation until approval and target repository context are clear.

## Outputs

- Implementation plan.
- API or UI contract notes.
- Test/build command plan.
- Risks and dependencies.
