# QA Testing

Use this skill when work needs test planning, QA review, acceptance validation, bug reporting, or release readiness evidence.

## Tool Selection

- Web E2E: Playwright or Cypress.
- JS/TS unit tests: Jest or Vitest.
- Flutter: flutter test and integration tests.
- iOS: XCTest.
- Android: JUnit, Espresso, Compose UI tests.

## Rules

- Test acceptance criteria first.
- Include happy path, edge cases, permissions, error states, and regression risk.
- Keep test data deterministic.
- Report evidence, not vibes.
- Block release when critical acceptance criteria fail.

## Outputs

- Test plan.
- QA evidence.
- Bug reports.
- Regression risk.
- Release readiness recommendation.
