# Agile Workflow

Use this skill when the user asks how the system should operate or when work must move between stages.

## Responsibilities

- Identify current stage and approval status.
- Select the next workflow, role, skill, checklist, and handoff.
- Prevent stage skipping.
- Explain allowed and blocked actions.

## Core Flow

```text
Idea -> Discovery -> PRD -> Design -> Architecture -> Backlog -> Development -> QA -> Release -> Growth
```

## Outputs

- Stage route.
- Role and skill selection.
- Checklist selection.
- Required artifacts.
- Next action.
