# Jira GitHub Delivery

Use this skill when approved product work needs Jira tickets, GitHub branch planning, PR planning, or implementation sequencing.

## Responsibilities

- Validate approval before Jira or GitHub side effects.
- Convert PRD and architecture into Epics, Stories, Tasks, and QA subtasks.
- Map Jira tickets to branches, commits, pull requests, tests, and release notes.
- Keep development blocked until `APPROVED_FOR_DEVELOPMENT`.

## Required Inputs

- PRD.
- Architecture.
- Acceptance criteria.
- Approval status.
- Target repository.

## Outputs

- Jira ticket draft or update plan.
- Development sequence.
- GitHub branch and PR plan.
- QA handoff.
