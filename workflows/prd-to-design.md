# PRD to Design

## Purpose
Convert PRD scope into user flows, screen inventory, UX states, and design handoff notes.

## Required Roles
- Product Designer
- Product
- QA Developer for testable UX states

## Steps
1. Read PRD and acceptance criteria.
2. Define main user flows.
3. Identify screens and interaction states.
4. Document accessibility and usability risks.
5. Produce design handoff.

## Outputs
- Design brief
- User flows
- Screen inventory
- UX risks

## Stop Conditions
- PRD flow is unclear.
- Key UX decision is unresolved.
- Accessibility requirements cannot be stated.
