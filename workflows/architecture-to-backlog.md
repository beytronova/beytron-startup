# Architecture to Backlog

## Purpose
Convert PRD and architecture into implementation-ready tickets.

## Required Roles
- Product
- Architect
- QA Developer
- Relevant developer roles

## Steps
1. Read PRD and architecture.
2. Split work into epics, stories, tasks, subtasks, and QA tasks.
3. Add acceptance criteria, technical notes, test notes, dependencies, and release impact.
4. Confirm definition of ready.

## Outputs
- Backlog draft
- Ticket dependencies
- Test notes

## Stop Conditions
- Tickets do not trace to acceptance criteria.
- Dependencies are missing.
- Definition of ready is not met.
