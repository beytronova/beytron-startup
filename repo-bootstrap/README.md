# Repo Bootstrap

Repo bootstrap defines how an approved incubator idea becomes a new product repository.

This stage is only allowed after:

```text
Approval Status = APPROVED_FOR_REPO_CREATION
```

## Files

- `product-repo-bootstrap.md`: end-to-end product repository creation flow.
- `product-repo-structure.md`: recommended initial repository structure.
- `../templates/PRODUCT_REPO_BOOTSTRAP.template.md`: bootstrap proposal template.
- `../checklists/repo-bootstrap-checklist.md`: gate before repository creation.

## Rules

- Do not create product repositories from raw ideas.
- Do not create product code during bootstrap planning.
- Do not create a repository until approval is explicit.
- Use project templates only after approval for repository creation.
- New product repositories must receive their own `AGENTS.md`.
- The new repository must link back to PRD, architecture, ticket drafts, and approval source.
