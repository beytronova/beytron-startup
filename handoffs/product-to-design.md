# Product to Design Handoff

## Purpose
Transfer product intent into UX/design work.

## Required Inputs
- PRD
- Target users
- User problem
- Acceptance criteria
- Non-goals
- Metrics

## Expected Outputs
- Design brief
- User flows
- Screen inventory
- UX risks

## Receiver
Product Designer

## Stop Conditions
- User flow is unclear.
- Acceptance criteria are not testable.
- Key constraints are missing.
