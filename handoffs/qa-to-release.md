# QA to Release Handoff

## Purpose
Transfer validated work into release preparation.

## Required Inputs
- QA results
- Test evidence
- Known issues
- Release scope
- Rollback risks

## Expected Outputs
- Release checklist
- Release notes
- Rollback plan
- Monitoring plan

## Receiver
DevOps Release

## Stop Conditions
- QA result is unclear.
- Critical blocker remains.
- Release approval missing.
