# v0.4 Phased Roadmap

## Phase 8: Usage & Installation

Status: Completed

Purpose: Make the plugin easier to install, verify, and invoke with practical prompts.

Delivered:

- `INSTALL.md`
- `USAGE.md`
- README updated to reference installation and usage guidance.

Outcome:

- Users have clear startup prompts.
- Codex has a documented first-read order.
- Installation verification is explicit.

## Phase 9: Jira/GitHub Execution Playbooks

Status: Completed

Purpose: Convert integration contracts into concrete operational sequences.

Delivered:

- `playbooks/README.md`
- `playbooks/jira-execution.md`
- `playbooks/github-execution.md`
- `playbooks/jira-github-delivery.md`

Outcome:

- Jira and GitHub side effects have approval-aware execution rules.
- Ticket-to-PR delivery has a standard path.
- Failure handling and evidence requirements are explicit.

## Phase 10: Repo Bootstrap Flow

Status: Completed

Purpose: Define how approved ideas become product repositories.

Delivered:

- `repo-bootstrap/README.md`
- `repo-bootstrap/product-repo-bootstrap.md`
- `repo-bootstrap/product-repo-structure.md`
- `templates/PRODUCT_REPO_BOOTSTRAP.template.md`
- `checklists/repo-bootstrap-checklist.md`

Outcome:

- Repository creation is gated by `APPROVED_FOR_REPO_CREATION`.
- Product repositories receive a minimum documentation structure.
- Development remains blocked until `APPROVED_FOR_DEVELOPMENT`.
