# Discovery Checklist

Use this checklist before moving from idea/discovery to PRD.

## Required Inputs
- Raw idea
- Target user or user hypothesis
- Problem statement
- Research evidence
- Assumptions
- Risks
- Approval status

## Checklist
- [ ] Raw idea is captured without losing original intent.
- [ ] Target user is specific or clearly marked as an assumption.
- [ ] Problem statement describes user pain and business reason.
- [ ] Current alternatives or competitors are identified.
- [ ] Facts are separated from assumptions.
- [ ] Evidence includes source or confidence level.
- [ ] Risks are documented.
- [ ] Open questions are listed.
- [ ] Continue/stop/research-more recommendation is explicit.
- [ ] Next approval state is stated.

## Pass Criteria
Discovery can move to PRD when the user, problem, evidence, assumptions, risks, and recommendation are clear enough to define MVP scope.

## Block Conditions
- Target user is unknown.
- Problem is vague.
- No evidence or assumptions are documented.
- Recommendation is missing.
- Approval state blocks PRD work.

## Missing Information Output
```text
Discovery is blocked because:
Missing information:
Risk if skipped:
Recommended next step:
```
