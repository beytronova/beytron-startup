# Examples

This directory contains golden path examples for running Beytron Startup from early idea work through delivery, QA, release, and growth.

Use examples after reading the routing registries and before producing large artifacts when the user asks for a full workflow.

## Available Golden Paths

- `idea-to-release-example.md`: raw idea to discovery, PRD, design, architecture, backlog, development, QA, release, and growth.
- `jira-ticket-to-pr-example.md`: approved Jira tickets to implementation, tests, QA handoff, and pull request preparation.
- `mobile-feature-example.md`: Flutter, iOS, or Android feature implementation path.
- `backend-api-example.md`: backend API, service, database, security, and test path.
- `growth-experiment-example.md`: post-release measurement, SEO/growth planning, experiment design, and follow-up ticket drafting.

## Usage Rule

Examples are references, not replacements for governance.

Before acting, still read:

- `config/workflow-map.yaml`
- `config/role-skill-map.yaml`
- `config/tool-access.yaml`
- Relevant `workflows/`, `roles/`, `skills/`, `checklists/`, and `governance/` files
- Target product repository `AGENTS.md` when coding is involved
